# Version 3.4 Milestone M6: Editable Content Inventory

Scope: a complete inventory of every editable item on the site, its current source, whether it is admin editable, whether a change requires a code deployment, whether that change appears immediately, and whether any database migration is needed to make it editable if it is not already. Nothing in the brief's example list is omitted; items not in that list but found during the audit are added at the end of each section.

Legend: **Source** is where the value actually lives today. **Admin editable** is whether a real admin UI exists to change it right now, not whether it theoretically could be. **Deploy required** is whether changing the value requires a code push. **Immediate** is whether, once changed, the new value reaches a visitor without a deploy, a cache clear, or a service restart.
