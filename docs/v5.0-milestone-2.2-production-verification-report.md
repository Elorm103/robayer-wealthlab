# Version 5.0 — Milestone 2.2 Production Verification Report

Real production evidence only — every result below was captured via a live, screenshot-by-screenshot walkthrough of the deployed `/admin/knowledge-base/` Search Diagnostics tool against the actual Vectorize index and D1 data, not a local test run.

## Method

Same 7 queries used in Milestone 2.1's own verification, run again after Milestone 2.2's backend deploy, one at a time, each confirmed by screenshot before moving to the next. This lets a direct before/after comparison stand on real, not estimated, numbers.

## Results

- **After:** top result **0.609 (high)** — vector similarity 0.459, keyword boost +0.150, title boost +0.000 (the document's actual title field is a generic site title, not literally the book title — the boost came entirely from keyword overlap in the body text, a useful real-world correction to a pre-deployment hand-estimate that assumed the title would carry it).

## Findings Discovered During Verification (Not Anticipated Before Testing)

1. **Search Analytics dashboard did not refresh after a new query** — `loadSearchAnalytics()` was only ever called once, at page load. Confirmed by watching "Total searches" stay frozen at the same value across all 7 queries in the same session, and cross-checked against the actual `knowledge_search_log` row count (which *was* increasing). Fixed in code (commit `2a5786d`); deployment currently blocked by the GitHub outage (see Deployment Guide).
2. **"Most retrieved documents" correctly showed empty, for a real reason, not a bug** — the searches counted in "Total searches" at the time predated migration 0038's `top_document_id` column, so they legitimately have no value for it. Once the refresh fix (finding 1) is live and new searches accumulate, this should populate correctly with no further code change needed.
3. **Embedding Versions panel showing "Not yet embedded" for all 38 documents** — confirmed as expected, not a bug: those documents were indexed by the last Full Rebuild, which predates this milestone's migration. See Known Limitations §7.
